# KeyNotes

理解一个概念，算清一个例子，再把它放回实际系统。KeyNotes 将机器学习与基础设施放在同一条学习路径中：模型质量和系统性能，往往是同一个工程决策的两个方面。

## 分两轮学习

第一轮先看动机、示意图和具体例子。在记住术语之前，试着用自己的话解释机制。第二轮再推导公式、检查前提，并追问方法在哪些情况下会失效。章节中的练习和交叉链接，帮助你完成这一步。

例如，[KV Cache](ml/llm/inference/kv-cache.md) 最初是为了复用注意力计算。分析它的内存开销，会自然引出[量化](ml/llm/inference/quantization.md)、[分页存储](ml/llm/inference/layers-pages.md)和[跨节点传输](infra/end-to-end-transfer.md)。数学上更快的算法，仍然可能被内存带宽限制。

```mermaid
flowchart LR
    D[数据与评价] --> M[模型与目标]
    M --> T[训练与适配]
    T --> I[推理与检索]
    I --> S[内存与通信]
    S --> D
```

这些箭头表示一个学习闭环：部署中的问题，可能暴露数据或评价用例的缺口，而不只是实现缺陷。
