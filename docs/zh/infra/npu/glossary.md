# 核心术语

## 硬件与身份

| 术语 | 英文 | 简明解释 | 排障时要问 |
| --- | --- | --- | --- |
| 裸片 | Die | 从晶圆切割出的硅片实体；封装内部可能有多个 die | 这是物理 Die ID 还是软件逻辑 ID？ |
| 芯片封装 | Package | 将一个或多个 die、互联和封装基板组合成可安装器件 | 一个封装里有几个 die？ |
| NPU | Neural Processing Unit | 面向神经网络和张量计算优化的处理器 | 具体厂商、型号和架构代际是什么？ |
| 设备 | Device | 运行时可枚举、分配和提交任务的加速器对象 | Device ID 与物理位置如何映射？ |
| Rank | Rank | 分布式通信域中一个参与者的逻辑编号 | Rank 到节点、Device、网口如何映射？ |
| AI Core | AI Core | NPU 中执行计算任务的核心资源 | 是矩阵核、向量核还是耦合架构？ |

## 存储与搬运

| 术语 | 全称 | 方向或作用 |
| --- | --- | --- |
| Host Memory | 主机内存 | CPU 可直接访问的 DRAM |
| Device Memory / GM | 设备全局内存 | NPU 侧的大容量内存，常见实现包括 HBM 或 DDR |
| Local Memory | 片上局部存储 | AI Core 附近的小容量高速存储，如 UB、L1、L0 等 |
| H2D | Host to Device | Host Memory → Device Memory |
| D2H | Device to Host | Device Memory → Host Memory |
| D2D | Device to Device | 一个设备内或设备之间的数据复制，需结合上下文判断 |
| P2P | Peer to Peer | 设备间绕过 Host 中转的直接访问或复制能力 |
| DMA | Direct Memory Access | 由专用引擎搬运数据，减少 CPU 逐字节参与 |
| MTE | Memory Transfer Engine | 昇腾 AI Core 中负责层级间数据搬运的引擎称呼 |

## 互联与通信

| 术语 | 简明解释 |
| --- | --- |
| PCIe | CPU、NPU、网卡等设备常用的 I/O 总线；H2D/D2H 常经过它 |
| PCIe Switch | 扩展和汇聚 PCIe 链路的交换器件，会影响可达性与共享带宽 |
| Scale-up | 节点内或紧耦合系统内的高带宽、低延迟扩展 |
| Scale-out | 通过网络把多个服务器或机柜扩展成更大的集群 |
| Collective | 多 Rank 参与的集合通信，如 AllReduce、AllGather、Broadcast |
| RDMA | 允许远端直接访问已注册内存的通信机制，降低 CPU 参与和复制开销 |
| RoCE | 在以太网上承载 RDMA 的协议族，通常需要配套拥塞与无损网络配置 |
| HCCL | 昇腾集合通信库，向上提供多 NPU 集合通信能力 |
| HCCS | 昇腾系统中的高速一致性互联称呼，具体能力依产品形态而定 |

## “面”相关词汇

| 术语 | 常见含义 |
| --- | --- |
| 控制面 | 建链、发现、配置、资源管理和状态维护，不承载主要业务载荷 |
| 数据面 | 真正搬运张量或消息载荷的高频路径；也可能被口语化地用于某类数据网络 |
| 参数面 | 分布式训练中承载梯度、权重和其他模型参数同步流量的网络平面 |
| 存储面/样本面 | 读取训练样本、模型、Checkpoint，或写入结果和日志的网络平面 |
| 业务面/管理面 | 任务提交、集群管理、监控和普通业务访问；不同方案的命名并不完全一致 |

!!! warning "先确认语境"

    “数据面”是功能角色，“参数面”常是按业务流量划分的集群网络。二者不是天然并列、互斥的同一分类。
    在通信库里，“数据面”可能恰好承载参数同步；在网络规划里，对方也可能把“数据面”当成样本或业务数据网络。
