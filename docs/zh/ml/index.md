# 🧠 机器学习：从一个问题到一个可靠的系统

机器学习通过数据估计模式，并使用这些模式进行预测或决策。学习一个算法只是其中的一部分：你必须定义任务、防止信息泄漏、选择目标、评估正确行为以及理解部署约束。

## 四条相连的轨道

| --- | --- | --- |
| 基础知识 | [机器学习工程](mle/index.md) | 解释一个基线、其假设和错误 |

## 初学者路线

选择一个小的预测任务。定义目标以及在预测时可用的信息。检查缺失值和重复实体，适当分割数据，并拟合一个简单的模型。使用与决策对齐的指标来评估它。解释至少三种错误，然后再选择更复杂的算法。

基础知识轨道涵盖了[学习范式](mle/learning-paradigms.md)、[数据清洗](mle/data-cleaning.md)、[回归](mle/linear-logistic.md)、[损失函数](mle/loss-functions.md)和[指标](mle/metrics.md)。你可以在具体例子中学习概率和线性代数，而不是将所有数学视为入学考试。

## 高级路线

问结论在假设失败时会发生什么变化：相关样本、人口变化、缺失标签、有限上下文、昂贵的推理或不完美的检索。将[实验设计](mle/improving-networks.md)和[训练诊断](mle/training-challenges.md)与每个模型决策连接起来。推导一个目标，实现一个小的例子，并将其行为与完整系统进行比较。

对于语言系统，分别评估检索和生成，区分事实基础和流畅输出，并在质量的同时测量内存和延迟。[基础设施](../infra/index.md)解释了为什么模型改进必须与有限的带宽、内存和同步成本共存。

## 一个将轨道连接起来的项目

构建一个小文档问答评估。使用 SQL 或 Pandas 验证源身份和分割。建立一个简单的检索基线，添加[RAG](llm/rag.md)，并根据检索覆盖率、证据使用和答案正确性来检查失败情况。测量标记计数、延迟和内存。只有在确定更好的数据、不同的检索器、微调或系统更改是否解决瓶颈后，才做出决定。

每个主题包括一个机制、假设和示例，这样你就可以返回到更深层次。目标是解释为什么一种方法有效，并识别何时无效。
