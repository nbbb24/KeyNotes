# 🧩 LoRA：用低秩更新适配模型

LoRA 冻结一个预训练的权重矩阵，并学习一个因子化的更新。它的动机是，有用的任务适应通常可以用比全密集更新更少的自由度来表示。

对于 $W\in\mathbb R^{d_{out}\times d_{in}}$：

$$
W'=W+\frac\alpha r BA,\qquad
A\in\mathbb R^{r\times d_{in}},\quad
B\in\mathbb R^{d_{out}\times r}.
$$

可训练的参数数量为 $r(d_{in}+d_{out})$。对于一个 $4096\times4096$ 的矩阵和秩 8，LoRA 使用 65,536 个权重而不是 16,777,216。这是该矩阵可训练权重的 256 倍减少，而不是总 GPU 内存的 256 倍减少。

## 🎯 初始化和目标

一个常见的初始化方法是让一个因子随机化，另一个设为零，这样初始更新就是零。如果两个因子都设为零，则会阻止对任一因子进行有用的首阶学习。注意力 Q/V 投影是常见的目标，但 K/O 和前馈投影也可以被适应。最佳选择是经验性的，并且取决于模型。

秩控制最大更新秩，而 $\alpha/r$ 控制原始公式中的缩放。秩、缩放、学习率、丢弃率、目标模块和训练数据相互作用；仅秩本身不是一个质量旋钮。

## 🎯 训练和部署

在训练过程中，计算 $Wx+(\alpha/r)B(Ax)$。对于一个兼容的普通密集层，在推理时将学到的更新合并到 $W$ 中。当需要交换多个适配器时，保持未合并的基础副本。量化主干需要小心：合并和重新量化可能会改变数值误差，并非每个服务后端都支持每种组合。

QLoRA 在冻结的量化主干上训练适配器。它也减少了基础权重内存，但激活和优化器状态仍然会贡献。LoRA 本身是一个适应参数化，而不是损失函数：它可以与 SFT 或偏好目标一起使用。

**练习。** 秩为 8 是否意味着调整后的完整矩阵的秩最多为 8？不是。只有 $BA$ 的秩最多为 8；$W+BA$ 可能是全秩的。
