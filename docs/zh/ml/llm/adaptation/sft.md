# 🎓 监督微调：教模型遵循目标行为

监督微调，或SFT，通过输入和期望输出的示例对预训练模型进行训练。对于聊天模型，这通常意味着对话，其中助手的响应展示了目标风格、任务和行为。

## 🎯 目标和数据格式

对于提示$x$和响应标记$y_1,\ldots,y_T$：

$$
L_{SFT}=-\sum_{t=1}^T\log\pi_\theta(y_t\mid x,y_{<t}).
$$

仅使用响应的设置会将提示标记从损失中屏蔽。其他食谱会在对话中训练更多内容，因此请说明惯例。始终一致地应用模型的聊天模板：角色分隔符、回合结束标记和特殊标记是模型学习的序列的一部分。

对于支持助手，一个有用的示例包括用户的问題、相关上下文、正确的回答以及在信息缺失时适当的不确定性。重复经过修饰但事实错误的答案可以高效地教给错误的行为。

## 🔄 可靠的训练工作流程

1. 定义任务并收集代表性、已审查的示例。
2. 如有必要，按来源/用户/时间进行分割，以避免近似重复的泄漏。
3. 检查标记化的示例、截断、掩码和目标边界。
4. 训练所有权重或适应性如[LoRA](lora.md)。
5. 在保留一般能力的同时，与基础模型比较任务质量。

打包示例可以节省填充空间，但必须保持边界和预期的注意力可见。较低的训练损失可能反映记忆化或重复数据，而不是更好的行为。

## 📌 SFT能做什么和不能做什么

SFT特别适用于输出格式、领域程序以及在数据中展示的指令。它不是连续更新大型事实数据库的可靠机制；[检索](../rag.md)可以在推理时提供变化的证据。微调也可能导致遗忘，因此请包括回归测试以确保应用程序仍然需要的能力。

**练习。** 如果一个答案在预处理过程中被截断了一半，模型可能会学到什么？不完整的响应模式或错误的结束边界。在解释训练曲线之前，请检查实际标记化的样本。
