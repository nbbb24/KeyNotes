# 🖼️ 高级多模态学习：将方法转化为研究问题

高级轨道专注于异质性、连接性、交互性和如何量化它们。在完成[多模态基础路径](multimodal.md)后，具备表示学习和受控实验的基本理解。

## 🧭 要调查的三个问题

**异质性：** 不同模态在采样率、噪声、结构、维度和语义抽象方面有何不同？波形和句子不应自动共享预处理或完整的编码器。

**连接性：** 哪些观察结果指的是同一个事件或概念？对应关系可以是时间上的、空间上的、实例级别的或语义上的。弱配对可能有用，但不能误认为精确的局部对齐。

**交互性：** 任务是通过添加独立信号解决的吗，还是一个模态改变了另一个模态的意义？将加法基线与[非加法融合](../multimodal/fusion.md)进行比较，并检查残余效益。

## 📊 研究风格的实验

陈述一个可证伪的假设，例如“时间对齐在音频和视频都具有信息时改善事件定位。”定义一个基线、对齐干预、匹配成本控制和保留度量。在保持内容不变的情况下扰动对齐。报告不确定性以及与假设相矛盾的例子以及支持它的例子。

迁移实验可以建议任务或模态之间的参数共享。单向的正迁移并不保证双向的迁移。转移矩阵是关于特定训练设置的证据，而不是模态不可变的分类法。

## 🔍 有批判性地阅读论文

识别发生了什么变化：数据、目标、架构、优化还是评估。检查一个声称的交互是否在强大的单模态基线下幸存下来。区分预测关联和因果结论。审查缺失模态假设以及评估分割是否排除了主体/会话泄漏。

**练习。** 一个融合模型击败了一个小的单模态基线，但没有击败一个容量匹配的基线。这是否建立了有用的跨模态交互？不。容量和优化仍然是替代解释。
