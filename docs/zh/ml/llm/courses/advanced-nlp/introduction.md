# 🚪 NLP 入门：从文本到可衡量的预测

自然语言处理始于定义任务、表示和评估协议。大型模型是可能的一个组件；它不取代明确的目标或可信的数据集。

## 🧭 以词袋基线开始

词袋向量计算文档中的词汇项数量。使用词汇表 `[good, bad, movie]`，`good good movie` 变为 `[2,0,1]`。线性分类器在这些特征上学习权重：

$$
z=w^\top x+b,\qquad p(y=1\mid x)=\sigma(z).
$$

词频本身不是学习的分类器权重。TF–IDF 使用语料库统计信息重新加权计数；这些统计信息应该在训练数据上拟合。稀疏基线速度快、可解释，并且通常在基于关键词的任务中具有竞争力。

## 🧩 表示遗漏的内容

`dog bites person` 和 `person bites dog` 在一元词频计数上相同。否定、顺序、长距离依赖关系和多义性需要更丰富的特征或上下文模型。N-gram 恢复局部顺序，但扩展了特征空间，并且仍然在未见过的组合中提供有限的一般化。

嵌入用学习的密集向量替换稀疏的词典身份。然后上下文模型使标记的表示依赖于其句子。这个进展增加了能力和成本；使用基线来确定哪些增加的复杂性实际上是有帮助的。

## 📊 实践实验

为了复习分类，按可能泄露信息的单位进行分割——例如产品、用户或时间——然后再拟合向量化器。训练一个词袋逻辑回归分类器和一个上下文模型。比较类特定的精确度/召回率，并检查涉及否定、讽刺和领域词汇的错误。更高的综合得分可能会隐藏对一个小但重要的子群体的退化。

**练习。** 一元模型能否区分 `not good` 和 `good`？它可以学习来自 `not` 的贡献，但不能可靠地建模所有上下文相关的否定范围。问题在于表达能力，而不是绝对无法使用该词。
