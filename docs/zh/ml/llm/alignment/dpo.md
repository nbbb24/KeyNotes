# 🗳️ 直接偏好优化

DPO 通过使用参考策略直接从用户选择或拒绝的响应对训练语言模型。它避免了经典基于 PPO 的 RLHF 管道中显式奖励模型训练和在线策略回滚循环。它仍然依赖于偏好数据的质量和覆盖范围。

## 🧭 偏好对数比

对于提示 x，优选响应 $y_w$，拒绝响应 $y_l$，以及参考 $\pi_{ref}$：

$$
\Delta=\log\frac{\pi_\theta(y_w\mid x)}{\pi_{ref}(y_w\mid x)}
-\log\frac{\pi_\theta(y_l\mid x)}{\pi_{ref}(y_l\mid x)},
$$

$$
L_{DPO}=-\log\sigma(\beta\Delta).
$$

序列对数概率之和等于合格响应标记的对数概率。参考相对差异很重要：DPO 询问当前策略在基线下的偏好对之间的变化。推导连接了 KL 正则化奖励目标和特定假设下的偏好模型；它并不证明每个数据集都完美遵循这些假设。

## 🧩 处理一对

假设当前选择/拒绝的概率差距为 -2，参考差距为 -4。那么 $\Delta=2$：当前模型在相对偏好上改善了所选答案，尽管该答案的绝对序列概率仍然较低。当 $\beta=0.5$ 时，模型化的偏好是 $\sigma(1)\approx0.731$，损失约为 0.313。

![直接偏好优化：原图 1](../../../../assets/notion/027-00.png)

简式比较当前策略相对固定参考策略，对偏好回答和落选回答的概率分别改变了多少。Sigmoid 将两者差值转成成对逻辑目标。

![直接偏好优化：原图 2](../../../../assets/notion/027-01.png)

标注图指出提示、胜出回答、落选回答和 $\beta$。两个对数比值要放在一起看：只提高胜出回答的概率，并非完整目标。

![直接偏好优化：原图 3](../../../../assets/notion/027-02.png)

两个策略—参考对数比之差就是偏好间隔。正值越大，说明在参考策略的基准上，当前策略越偏向胜出回答。

![直接偏好优化：原图 4](../../../../assets/notion/027-03.png)

比较表概括一种常见的 RLHF 流程，不能当作 PPO 或 DPO 的普遍定律。PPO 不一定需要单独训练的奖励模型；DPO 也不保证在所有场景更稳定、质量更高或计算更省。

*原始图表将隐式奖励、参考相对概率比率和更简单的成对训练路径连接起来。Sigmoid 映射偏好对数比，而不是原始答案质量评分。*

## ⚠️ 关键限制

增加选择/拒绝的概率差距并不保证所选答案的绝对概率上升；两者都可能下降。响应长度、标记掩码、聊天模板和数据分布会影响训练。一些食谱添加了所选响应的 NLL 正则化或使用目标变体；将它们与原始 DPO 区分开来。

离线偏好对可能不覆盖由演化的策略产生的输出。评估保留的偏好、任务正确性、长度/风格变化以及一般能力的保持情况。较大的 beta 会影响目标参数化，不应将其描述为一个通用的“更对齐”旋钮。

**练习。** DPO 是否可以与 LoRA 结合使用？是的。DPO 指定了目标，而 LoRA 指定了哪些权重更新是可训练的。
