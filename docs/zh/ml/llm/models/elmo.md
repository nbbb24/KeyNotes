# 🔤 ELMo：一种随上下文变化的词表示方法

静态词嵌入为一个词类型提供一个向量。ELMo解决了多义性问题：“银行”在金融句子和河流句子中应该有不同的表示。它从双向语言模型中学习上下文特征，然后将这些特征暴露给下游任务。

## ⚙️ 表示是如何构建的

原始系统使用基于字符的标记表示，然后是堆叠的前向和后向LSTM。前向模型从左到右预测；后向模型从右到左预测。它们在对应位置的状态被连接起来。这比说一个递归模型在执行因果预测时可以同时看到两个方向更精确。

下游任务学习层的加权组合：

$$
\operatorname{ELMo}^{task}_k=\gamma^{task}\sum_{j=0}^{L}s_j^{task}h^{LM}_{k,j},
$$

其中 $s_j$ 是 softmax 归一化的层权重，$h_{k,j}$ 是来自不同层次的标记表示，$\gamma$ 是一个学习到的比例因子。标记层和不同的递归层可能提供不同的信息；只使用顶层会丢弃这种灵活性。

## 🧩 通过一个例子来说明

在“银行提高了利率”中，左右方向的递归状态编码了诸如 `raised` 和 `rates` 的线索。在“银行是泥泞的”中，不同的上下文即使拼写相同也会改变向量。情感或实体模型可以使用这些向量作为额外的输入特征，而无需从其小标记数据集中重新学习所有语言结构。

## 🎯 ELMo对迁移学习的教义

预训练和下游任务是不同的。一个语言模型目标提供广泛有用的表示；一个任务特定的读取器学习如何使用它们。上下文化并不保证事实正确性或消除领域转移。字符输入有助于形态学和不寻常的拼写，但不会使未知术语自动理解。

LSTM 计算在每个方向上仍然是顺序的，这与 Transformer 相比限制了训练并行性。这种历史权衡帮助解释了向 [BERT](bert.md) 的过渡，而 ELMo 仍然是基于特征的迁移和学习层混合的一个清晰例子。

**练习。** 如果下游任务只改变其层混合权重，语言模型权重是否必然也改变了？不一定。特征提取和微调是两个独立的选择。
