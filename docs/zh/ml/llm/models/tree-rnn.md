# 🌳 树形 RNN：沿层级结构组合意义

序列 RNN 以线性顺序结合标记。基于树的递归模型根据提供的层次结构（如句法分析）结合子节点。它的动机是组合意义：短语“not very good”应该通过单词之间的交互来解释，而不仅仅是它们各自的得分。

## 🧭 父节点上的组合

一个简单的二叉递归网络计算

$$
h_p=\tanh(W[h_l;h_r]+b).
$$

这里 $h_l$ 和 $h_r$ 分别总结了左子节点和右子节点。相同的组合参数可以在树中重用。叶子节点可能从词嵌入开始；内部节点代表短语。分类器可以在根节点或标记的子树上操作。

Tree-LSTMs 扩展 LSTM 单元以处理多个子节点。一个子和变体聚合子隐藏状态，并为每个子节点使用单独的遗忘门。N-ary 变体可以区分有序的子节点位置。这种区别很重要：除非在其他地方编码顺序，否则简单地求和子节点对它们的顺序不敏感。

## 🧩 示例：否定范围

比较“not [very good]”和“[not very] good”。不同的分组改变了组合路径。一个解析树可以提供有用的结构偏置，但错误的解析也可能将模型引向不适当的方向。这就是为什么必须分别评估树的质量和下游任务质量的原因。

平衡的树可以比长链缩短远叶子之间的组合步骤。它不会消除梯度问题，实际的解析树也不必是平衡的。可变结构也复杂了批处理和高效执行。

## 📌 当这种视角有帮助时

树模型在研究句法、组合情感和层次数据方面很有用。它们与决策树不同：决策树通过特征测试路由示例，而 Tree-RNN 在输入结构上计算向量表示。它们还不同于 Tree of Thoughts，后者在生成候选时进行推理时间搜索。

**练习。** 如果两个子向量在共享变换之前相加，交换这些子节点是否会影响结果？除非有额外的位置依赖信息，否则不会。当需要这种区别时使用有序组合。
