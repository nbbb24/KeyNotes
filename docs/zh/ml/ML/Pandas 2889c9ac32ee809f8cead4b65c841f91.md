# Pandas

### Q1: What is Pandas?

Pandas is a Python library for data manipulation and analysis, built on top of NumPy.

It provides two main data structures:

- **Series** – one-dimensional labeled array (like a column)
- **DataFrame** – two-dimensional labeled data (like an Excel table)

---

### Q2: How do you create a DataFrame?

```python
import pandas as pd

data = {'Name': ['Tom', 'Jerry'], 'Age': [20, 22]}
df = pd.DataFrame(data)
```

---

### Q3: How to read and write data?

```python
df = pd.read_csv('file.csv')       # Read CSV
df.to_csv('output.csv', index=False)  # Write CSV

df = pd.read_excel('file.xlsx')
df.to_excel('output.xlsx', index=False)
```

---

### Q4: How to check basic info?

```python
df.head()         # first 5 rows
df.tail(3)        # last 3 rows
df.shape          # (rows, columns)
df.info()         # summary of data types
df.describe()     # summary statistics
df.columns        # list of column names
```

### Q5: How to select data?

```python
df['Age']                  # single column (Series)
df[['Name', 'Age']]        # multiple columns
df.iloc[0:3]               # by position
df.loc[0:3, ['Name']]      # by label
df[df['Age'] > 20]         # filter condition
```

---

### Q6: How to sort and rank?

```python
df.sort_values(by='Age', ascending=False)
df.sort_index()
df['Age'].rank()
```

### Q7: How to handle missing data?

```python
df.isnull().sum()              # count NaN
df.dropna()                    # remove rows with NaN
df.fillna(0)                   # replace NaN with 0
df.fillna(df['Age'].mean())    # fill with mean value
```

---

### Q8: How to rename columns?

```python
df.rename(columns={'Name': 'FullName'}, inplace=True)
```

### Q9: How to change data types?

```python
df['Age'] = df['Age'].astype(float)
```

---

### Q10: How to handle duplicates?

```python
df.duplicated().sum()      # check duplicates
df.drop_duplicates(inplace=True)
```

---

### Q11: How to use `groupby()`?

```python
df.groupby('Department')['Salary'].mean()
df.groupby(['Department', 'Gender']).agg({'Salary': 'mean', 'Age': 'max'})
```

### Q14: What is the difference between merge, join, and concat?

| Method | Purpose | Similar To SQL |
| --- | --- | --- |
| `merge()` | Combines DataFrames on keys | JOIN |
| `join()` | Joins by index | JOIN |
| `concat()` | Stacks along rows or columns | UNION |

```python
pd.merge(df1, df2, on='id', how='inner')
df1.join(df2, lsuffix='_A', rsuffix='_B')
pd.concat([df1, df2], axis=0)    # vertical
```

### Q16: How to detect outliers?

```python
df[(df['Salary'] > df['Salary'].quantile(0.95))]
```

---

### Q17: How to use `query()` and `eval()`?

```python
df.query('Age > 30 and Salary < 80000')
df.eval('Total = Salary * 1.1')
```

### Q19: How to handle datetime data?

```python
df['Date'] = pd.to_datetime(df['Date'])
df.set_index('Date', inplace=True)
df['Month'] = df.index.month
df.resample('M').sum()    # monthly aggregation
```
