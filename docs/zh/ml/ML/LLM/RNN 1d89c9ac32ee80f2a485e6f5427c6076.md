# RNN

- **梯度消失**：长序列依赖时，梯度会逐渐缩小，导致学习不到远距离依赖。
- **梯度爆炸**：反向传播时梯度可能变得非常大 → 需要 **梯度裁剪（gradient clipping）**。
- **训练慢**：序列依赖导致并行性较差。

## **改进模型**

- **LSTM (Long Short-Term Memory)**
    - 引入 **门机制（输入门、遗忘门、输出门）**，解决长依赖问题。
    - **遗忘门 (Forget Gate)**：决定丢弃多少旧信息
    - **输入门 (Input Gate)**：决定存入多少新信息
    - **输出门 (Output Gate)**：决定输出多少信息
- **GRU (Gated Recurrent Unit)**
    - 简化版 LSTM，合并部分门结构，计算更快。
    - **更新门 (Update Gate)**：控制信息保留多少
    - **重置门 (Reset Gate)**：控制丢弃多少过去信息
- **双向 RNN (BiRNN)**
    - 前向 + 反向传播，捕捉上下文。
- **注意力机制 (Attention)**
    - 解决长依赖问题 → 过渡到 Transformer。
