# BLEU (precision)

![image.png](Automatic%20evaluation/image%201.png)

**Pros:**

○ relaxes exact match
○ Handles tasks with multiple target sequences
○ correlation with human preferences (MT)

**Cons:**

○ semantically similar words ignored

# ROUGE (recall)

![image.png](Automatic%20evaluation/image%202.png)

**Pros:**

○ relaxes exact match
○ correlation with human preferences (MDS)

**Cons:**

○ semantically similar words ignored
