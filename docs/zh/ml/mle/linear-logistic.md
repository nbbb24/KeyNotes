# Logistic Linear

### Sigmoid的作用：

1️⃣ **概率解释**

- 输出可直接解释为 $P(y=1∣x)$

2️⃣ **连接线性与分类**

- 输入：线性模型$w^Tx$
- 输出：非线性概率

3️⃣ **可导，适合优化**

- Sigmoid 连续、可导
- 方便用梯度下降

### 损失函数

$\mathcal{L}(y, \hat{y}) = -\left[ y \log(\hat{y}) + (1 - y)\log(1 - \hat{y}) \right]$

其中：

$y^=σ(wTx)$
