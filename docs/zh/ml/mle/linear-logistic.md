# 📉 线性回归与逻辑回归：相似分数，不同目标

两种模型都从线性分数 $z=w^Tx+b$ 开始。区别在于分数的含义，以及用什么目标估计它。线性回归直接预测数值响应；逻辑回归通过非线性连接函数描述二分类结果的概率。

## 🧭 线性回归

连续目标最简单的模型是 $\hat y=w^Tx+b$。最小二乘最小化残差平方和，因此更重视较大误差。在方差恒定的高斯噪声模型下，它对应最大似然估计。

一个系数表示其他编码特征固定时，该特征变化如何影响预测。这是模型解释，不自动等于因果效应。输入相关时，即便预测稳定，单个系数也可能不稳定。

## 🧩 逻辑回归

对 $y\in\{0,1\}$，逻辑回归使用 Sigmoid：

$$
p(y=1\mid x)=\sigma(z)=\frac{1}{1+e^{-z}}.
$$

对数优势满足 $\log(p/(1-p))=z$。因此，固定其他输入后，某特征增加一个单位，会让模型中的 Odds 乘以 $e^{w_j}$，而不是让概率增加固定数值。

二元交叉熵来自 Bernoulli 似然：

$$
\ell(y,z)=\log(1+e^z)-yz.
$$

实际实现应使用基于 Logits 的数值稳定版本，避免在极端分数上直接计算 `log(sigmoid(z))`。

## 🧩 算一个例子

设 $z=-2+0.5x$，$x$ 使用固定单位。$x=2$ 时，$z=-1$、$p\approx0.269$；$x=4$ 时，$z=0$、$p=0.5$；$x=6$ 时，$z=1$、$p\approx0.731$。分数线性变化，但概率曲线在接近 0 和 1 时变平。

```python
# runnable-example
from math import exp
sigmoid = lambda z: 1 / (1 + exp(-z))
assert abs(sigmoid(-1) - 0.2689414214) < 1e-9
assert sigmoid(0) == 0.5
assert abs(sigmoid(1) - 0.7310585786) < 1e-9
```

阈值为 0.5 时，决策边界是超平面 $w^Tx+b=0$。非线性特征变换可以在原始输入坐标中形成非线性边界，同时仍让模型对参数保持线性。

## 🚀 进阶

完全可分的数据，可能使没有正则化的逻辑回归系数趋向无穷，因此正则化不只是形式上的偏好。比较系数大小或使用统一惩罚前，应考虑标准化；标准化器仍然只能在训练数据上拟合。

多分类 Softmax 回归联合描述互斥类别；独立 Sigmoid 更适合多个标签可以同时为真的多标签任务。它们表达不同目标假设，不是可以随意互换的激活函数。

概率阈值应依据应用成本和验证结果确定。模型设定错误、分布变化或类别采样比例改变时，逻辑回归并不保证概率校准。

## ✅ 检查理解

**问题：**为什么不直接用普通最小二乘拟合二元标签？**回答：**它可以作为基线，但预测不一定落在 $[0,1]$，误差假设也与 Bernoulli 模型不同，概率解释较弱。
