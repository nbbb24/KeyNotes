# 🛠️ 改进神经网络：让实验说明增益来源

改进模型，是在明确预算下改善明确结果：准确率、校准、延迟、内存或鲁棒性都可能是目标。更大模型提高某项分数，却超过部署预算，并不自动算改进。

## ⚠️ 建立基线和错误分类

固定数据划分、指标、预处理、随机种子策略和训练预算，记录线性模型或小网络等简单基线。按错误类别分析，而不是把所有失败都归因于容量。

客服消息分类器的错误可能来自标签含糊、稀有类别、长消息、多语言混合或术语变化，各自对应不同实验。为原本容易的类别补充更多样本，不一定改善最弱类别。

## 🎯 用学习曲线选择下一步

分别绘制性能随优化步数、训练集大小变化的曲线。训练与验证都差，可能是欠拟合或优化缺陷；差距扩大，可能是过拟合或分布不匹配；随数据增多而改善，支持继续采集，但要确认新增数据独立且有代表性。

受控实验每次主要检验一个假设。“增加层数、更换优化器、加入增强、延长训练”同时发生，可能提高分数，却无法告诉你哪个变化有效。

## 🧩 例子：有针对性的数据增强

分类器整体准确率为 94%，低光照图片只有 70%。在**训练集**采集或合成合理低光照变化，保持一组真实低光照验证样本不变，并使用相同基线预算比较。如果整体提高到 95%，低光照仍为 70%，干预并没有解决预期失败。

增强必须保留目标。水平翻转对某些物体分类合理，对左/右标签却不合理；文本改写也可能意外删除否定词。大规模使用前先检查转换例子。

## 🏗️ 超参数与架构

先在有意义的范围搜索学习率，通常使用对数尺度，再研究正则、有效批量、调度和模型容量。固定调参预算，不在最终测试集上选择配置。

| 证据 | 候选干预 | 如何测量 |
| --- | --- | --- |
| 标签噪声或矛盾 | 重标注，改进目标定义 | 一致率和留出误差 |
| 稀有失败模式 | 定向采集数据 | 子群体精确率、召回率 |
| 容量过多 | 正则化或更小模型 | 训练验证差距与验证损失 |
| 容量未利用 | 改善调度或架构 | 小数据拟合与学习曲线 |
| 服务瓶颈 | 量化、批处理、蒸馏 | 质量、延迟与内存的权衡 |

架构变化应匹配问题结构：卷积利用局部空间结构，注意力处理依赖内容的交互。没有理由地增加复杂度，会扩大搜索空间和排障负担。

## ⚖️ 进阶：公平比较

可行时，对有希望的配置使用多个种子或重采样划分重复实验。报告不确定性与搜索成本，而不只是最佳运行。根据问题，选择相同数据、算力或延迟预算比较，并通过消融隔离各组件贡献。

选定后，在留出的测试集上进行最终评价，并监控部署变化。预处理或检索变更，也可能让原先公平的模型比较失效。

**练习：**三个种子的改进分别为 +0.3、−0.2、+0.1 个百分点，能确定有增益吗？**答案：**仅凭这些数字不能。还需看不确定性、配对错误，以及差异在业务上是否有意义。
