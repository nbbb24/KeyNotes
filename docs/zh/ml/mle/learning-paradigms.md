# 🎓 学习范式：训练信号从哪里来

学习算法需要一条规则，判断一次改变是否有帮助。不同学习范式主要区别在于**训练信号的来源**，而不只是使用哪种神经网络。选择模型之前，先明确训练时有哪些信息，以及部署后要做什么决策。

## 🔍 用同一个场景理解不同范式

假设一个服务不断收到客户消息，同样的文本可以构建不同系统：

| 任务 | 训练信号 | 学习范式 |
| --- | --- | --- |
| 预测人工标注的客服类别 | 消息与类别配对 | 监督学习 |
| 没有类别时发现反复出现的主题 | 相似性或表征目标 | 无监督学习 |
| 预测原始消息中被遮住的词 | 从文本本身构造目标 | 自监督学习 |
| 少量标注配合大量未标注消息 | 标签加上对未标注数据的假设 | 半监督学习 |
| 选择一连串帮助动作，提高最终解决率 | 动作之后产生的奖励 | 强化学习 |

这些类别可以组合。一个语言模型可能经历自监督预训练、监督指令微调和基于奖励的后训练。改变范式的是数据与训练目标，并不一定要改变模型架构。

## 🎯 不同目标分别在优化什么

监督学习最小化经验损失，例如：

$$
\hat R(\theta)=\frac1n\sum_{i=1}^{n}\ell(f_\theta(x_i),y_i).
$$

$x_i$ 是输入，$y_i$ 是目标，$\theta$ 是学习得到的参数。独立评价集用来估计这套拟合过程能否泛化。

无监督方法也有明确目标。K-means 最小化样本到聚类中心的距离，并不会发现唯一正确的“客户类型”。特征、距离度量和簇数本身都包含假设。

自监督从没有人工标签的观测中构造预测问题。下一词元预测把前缀作为输入、后续词元作为标签。因此，“不需要人工标注”不等于“没有预测目标”。

强化学习优化期望回报，常见形式为 $E[\sum_t\gamma^t r_t]$。动作影响未来观测，奖励可能延迟出现，如何收集更有用的数据也是问题的一部分。仅把分类标签换成数值分数，不会自动形成有意义的序列决策任务。

## 📌 一个小型设计练习

你有 200 条标注消息和 20 万条未标注消息。先使用预训练文本表征建立监督基线，再在留出集上检验自监督适配或伪标签是否有帮助。未标注数据不一定有益：不同语言、时间段或客户群体可能引入分布变化。

如果任务只是路由，小分类器可能比指令模型更容易评价和维护；反过来，固定类别集合又不适合开放式摘要。

## 🚀 进阶：分开看三个维度

区分**学习范式、模型家族与评价协议**。决策树和神经网络都可以做监督学习。分类器可以离线训练，却在持续变化的在线环境中使用。主动学习描述怎样选择待标注样本，不能代替损失函数的定义。

对于时间序列或同一实体反复出现的数据，应先按时间或实体划分。随机划分可能让同一实际情形出现在训练集和测试集中，使任何范式的结果都显得过于乐观。

## ✅ 检查理解

**问题：**下一词元预训练算监督还是无监督？

**回答：**通常称为自监督，因为数据提供自己的标签；优化过程仍使用监督预测损失。与其只争论名称，不如说明标签怎样构造。
